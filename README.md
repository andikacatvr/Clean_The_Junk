# Clean_The_Junk

Game 3D Aktivis Lingkungan (Low-Poly River Adventure) berbasis Three.js & Tailwind CSS.

## Fitur Utama
- Bersihkan sampah di sungai dan tukarkan ke Truk Daur Ulang.
- Rintangan ular predator dengan pergerakan meliuk yang dinamis.
- Suasana senja berbintang (*starry twilight sky*) dengan pencahayaan golden hour dan bulan sabit.
- Efek suara sintetis (termasuk lompatan boing) menggunakan Web Audio API.

## Menjalankan Game
```bash
npm install
npm run dev
```
Buka browser di `http://localhost:5173/`
